# join

## 개요
그룹 참여 확인 페이지. QR코드 스캔 또는 공유 링크 접속 후, 사용자가 행사와 연결된 그룹 가입을 확인하는 페이지이다.

## 주요 파일

| 파일 | 설명 |
|------|------|
| `[code]/page.tsx` | 그룹명 표시, 가입 확인 액션, 사용자를 그룹 멤버로 추가 |

## AI 에이전트 가이드

- `Group.code`(nanoid 8자)가 URL 파라미터
- 인증 필요 — 미인증 시 `/login?callbackUrl=...`으로 리디렉트
- 가입은 멱등성 보장: 이미 멤버인 사용자를 추가해도 오류 없음
- 가입 완료 후 행사 페이지 또는 홈으로 리디렉트
